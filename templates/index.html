Input Files

iThe run is filed the way the OAEI tracks are, as context/source-target with the time on the end, for example conference/cmt-confof-20260827-163210. The context comes from the Matching Settings card and the two names from the boxes here. Everything stays under uploads/, so the OAEI data is never touched, and the time keeps every run of a pair rather than replacing the one before it.

There is nothing to score if there is no reference file, so there is no precision, recall or F1.
