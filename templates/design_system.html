The design language for the Agent-OM web interface, taken from the ANU Web Style Guide and its sub-pages. Everything below was read from that guide; where the guide is silent, the gap is marked rather than filled in quietly.

This is our own implementation of the published design language, not the ANU CSS framework. That framework is served from webstyle.anu.edu.au to ANU-hosted Drupal sites and is not available to a local research tool. Class names below match the guide's names wherever it gives one. Nothing here has been reviewed or approved by ANU Brand and Marketing Services, which the guide requires before any real ANU site goes live.

1. Foundations

ANU web style is at framework version 5, released November 2022. That release replaced the old charcoal and platinum scheme and made gold and black the University colours, widened the viewport, and introduced a new set of style classes. The layout is a 12-column grid on Bootstrap 5 breakpoints, and every page must pass a WCAG 2.1 check.

Three ideas carry through the whole guide and are worth stating before the detail: gold is a highlight and not a surface, contrast is a hard requirement rather than a preference, and colour may never be the only thing that carries meaning.

2. Colour

The primary palette is five colours. There is no secondary palette for websites.

Day and night

The interface has two modes, and both are the same palette rather than two palettes. The guide approves black text on white and white text on black equally, so night mode is an inversion rather than an invention. On a black background the guide also turns links gold and swaps the black button for the white one, and both of those happen automatically.

Colour is held in two layers. The five brand colours never change. Below them sit semantic tokens naming what a colour is for — --page-bg, --surface, --muted, --accent, --link and the rest — and only those are swapped. Every pair in both modes was measured against the 4.5:1 requirement; the tightest is 5.33:1 by day and 4.82:1 by night.

One colour has no ANU equivalent. The palette's only grey, unigrey, is a font colour for light backgrounds and is far too dark to read on black, and the guide offers no dark-mode secondary. Night mode therefore uses #C9C9C9 for dimmed text, at 12.68:1 on black. It is the single value in this system that is not from the palette or derived from it.

The mode follows the clock on the reader's own machine, night from 18.00 to 06.00, and the symbol in the masthead overrides it. One button cycles through three states, each with its own symbol and no wording at all: a half-filled circle while the clock decides, a sun for day, a moon for night. The choice is remembered, so it holds across a reload and across both pages, and coming back round to the half circle hands the decision to the clock again, which re-checks every minute so the page turns over at dusk without a reload.

A control with no words still has to say what it is. The button carries no text, but its title and aria-label name the current mode and what activating it will do, so the meaning is available on hover and to a screen reader.

Rules

  • Gold should rarely be used as a background and must not cover more than one eighth of a page or banner.
  • Unigrey is a font colour only. It is never a background.
  • Gold Tint is a background only. It is never a font colour.
  • Colour must not be the only visual means of conveying information.
  • Text colour classes: .text-black, .text-unigrey, .text-gold, .text-white.
  • These are web colours. Print colours differ and need the Marketing Office.

3. Approved contrast pairs

Every combination must reach a contrast ratio of at least 4.5:1. The guide publishes a pass/fail matrix; this is the part of it that governs the colours we actually use.

The consequence worth remembering: gold text on white only passes at 24px regular or 19px semibold and above. Gold is therefore never used for body copy in this interface, only for borders, rules and large headings.

4. Typography

Public Sans is the ANU web font, chosen for accessibility and fast loading, with sans-serif as the fallback. Body text is 1em / 16px, black on white, and always left-aligned — the guide rejects justified text as hard to read on screen. Underlining is reserved for links.

Heading scale

All headings are normal weight with 0.01em letter spacing and a 10px bottom margin.

Rules

  • Exactly one <h1> per page, and it is the page title.
  • Never skip a level: sections are h2, subsections h3.
  • Headings use sentence case.
  • A class may be used to make a semantic level look like another size, so the outline stays correct while the visual weight suits the layout.
  • .scrnhide hides a heading visually but keeps it for screen readers.

Text utilities

  • .large — 1.25em, for introductory text
  • .small — 0.85em, for disclaimers and notes
  • .caption — 0.85em, for image captions
  • .uppercase — exists, but the guide says it is not recommended

5. Spacing

Six steps, ten pixels apart. Classes read {property}{sides}-{size}, optionally with a breakpoint: {property}{sides}-{breakpoint}-{size}. Property is m or p; sides are t b l r x y or blank for all four. Negative margins use an n prefix, and grid gutters use g-{size}.

0 0px
1 10px
2 20px
3 30px
4 40px
5 50px

Padding makes space inside a border; margin makes space between two elements outside their borders.

6. Layout and grid

Twelve equal columns, nested container → row → col. Column classes are col-{breakpoint}-{1..12}. The guide notes that in practice widths of 3, 4, 6, 8, 9 and 12 at the sm, md and lg breakpoints cover almost everything.

Layouts restructure at breakpoints rather than shrinking, so text stays at a readable size on every device. Related utilities: .w10–.w100 in 5% steps for width, .equal on a row to level column heights, and .text-left, .text-center, .text-right for alignment. Responsive width classes fall back to 100% below their breakpoint.

Bands

A band paints the full viewport width while the container inside keeps content aligned with the rest of the page: .band-black-wrap, .band-tint-wrap, .band-white-wrap. Text colour flips automatically for contrast. The guide suggests running darker bands at the top of a page and lighter ones towards the bottom.

7. Buttons

Three classes, all with a 3px border and square corners. The guide gives no border radius, which is why nothing in this interface is rounded. .anu-btn-black is for light backgrounds and .anu-btn-white for dark ones. Width classes w20…w100 apply. 

<a class="anu-btn-black">Start matching</a>

The guide applies these to <a> elements. This interface puts them on <button> elements, because they perform actions rather than navigate; the styling is identical.

8. Boxes and borders

A plain .box is nothing but 10px of padding and a 10px bottom margin. Borders are added separately, 1px by default and 3px in the -thick- variants, in gold, black or white. White borders are for dark backgrounds only. Single sides use bdr-{side}-{colour}.

box box-bdr-gold
box box-bdr-black
box box-bdr-thick-gold

Box headers pair with a content box: .box-header-black and .box-header-tint. Width and alignment classes go on the parent, never on the box itself.

Dividers break long content into sections: .divider-solid (1px gold), .divider-gold, .divider-black and .divider-white (all 3px).

9. Forms

Form containers are .anuform, .anuform-inline-tint or .anuform-inline-black. A .field groups a label with its input, .text styles text inputs, and .instruction styles helper text underneath. Required labels take .req, which draws the red asterisk.

Helper text uses the instruction class.

Accessibility requirement: the label's for must equal the input's id, and required fields carry both class="req" on the label and required aria-required="true" on the input, so the requirement reaches assistive technology and not just the eye.

10. Messages

Four message styles, plus .msg-inline. Their colours and icons are fixed and cannot be changed. Gold and white text are prohibited on every message style, because those combinations are not accessible.

msg-error — something failed and needs attention.

msg-warn — something needs care before continuing.

msg-info — background detail worth knowing.

msg-success — the action completed.

11. Tables

By default a table has an outer border, no inner borders and no shading. Header cells use <th> with a tinted background and bold text. Border variants are .tbl-row-bdr, .tbl-col-bdr, .tbl-cell-bdr and .tbl-space; widths use .tbl10–.tbl100 rather than pixels, so tables stay responsive. A wide table can be wrapped in .fullwidthscroll.

Every table needs a <caption> immediately after the opening tag, and header cells need scope="col" or scope="row". Both tables on this page follow that rule.

12. Links and lists

  • Links are University blue, with no underline until hover, when they turn bronze and gain one. Link colour adjusts automatically on coloured backgrounds; on black it becomes gold.
  • .underline and .nounderline force the two states.
  • .link-ext marks a link that leaves ANU; .link-new-win warns that a link opens a new window. Both should be paired with a title attribute.
  • .readmore is a smaller link prefixed with ».
  • Lists: .list-circle, .list-square, .list-lower-alpha, .list-upper-roman and siblings; .nobullet and .noindent strip decoration; .list-link renders a list of links each ending in »; .hangindent is for bibliographies.

13. Other components

These are part of the guide but have no role in a single-screen tool. They are recorded so the system stays complete.

  • Collapsible — .accordion on the heading, .panel on the content. Every accordion heading needs tabindex="0", and every tabindex must be 0 so the reading order is not scrambled.
  • Page tabs — .pagetabs-nav-tint or -black, .pagetabs-select for the active tab, .tab-content and .tab-pane. The heading covering all tabs sits above the tab bar.
  • Breadcrumbs — <div id="breadcrumb">, separated by ». The current page is not a link.
  • Dates — .dateblock with .day, .month, .year; times as HH.MM am.
  • Pull quotes — .pullquote, 50% width, centred, slightly larger than body text, in quotation marks.
  • Images — responsive by default with no width or height attribute; fixed sizes use w{n}px; ratios use ratio-16-9 and friends. Alt text is required, empty (alt="") only when the image is decorative. Upload at 2× the display size. Captions use .caption and must not repeat the alt text.
  • Carousel — Bootstrap markup with aria-label on the indicators and visually-hidden control labels.
  • Features — homepage only, first item, up to seven, each with a title, summary and image, refreshed at least monthly.
  • Overlap — .overlap with .overlap-child, positioned by {side}-{size}, at most two children, stacking below 992px.

14. Accessibility

Every ANU site must pass WCAG 2.1. The rules collected across the guide's pages are:

  • Contrast of at least 4.5:1 for text.
  • Colour must never be the only means of conveying information.
  • Gold text needs 24px regular or 19px semibold to pass on white.
  • Gold and white text are prohibited on message styles.
  • One h1 per page and no skipped heading levels.
  • Labels bound to inputs by for and id; required fields marked visually and in the accessibility tree.
  • Tables need captions and scope on header cells.
  • Images need alt; decorative images take alt=""; a linked image's alt describes the link's function.
  • Interactive elements need tabindex="0", never a positive value.
  • Link text describes its destination rather than showing a bare URL.

The guide does not specify a focus indicator. Since a visible focus state is a WCAG 2.1 requirement, this system defines one: a 3px gold outline offset by 2px, applied to every link, button, input, select and the information symbols.

15. Writing style

  • Sentence case everywhere. Only the first letter and proper nouns are capitalised, in headings and titles alike. Proper nouns keep their capitals, which is why Agent-OM Design System and Agent-OM Web Interface are capitalised as the names of things while ordinary headings are not.
  • Australian spelling: -ise not -ize, colour not color.
  • Active voice, plain English, no internet abbreviations.
  • Numbers: spell out one to nine, numerals from 10, commas in thousands.
  • Dates: Thursday 17 March 1917, no commas.
  • Acronyms spelled out on first use with the acronym in brackets.
  • Link the meaningful words, not the raw URL.

The interface text follows this. Buttons read "Start matching" and "Save keys" in sentence case, and messages are written in plain English.

17. Gaps and departures

Recorded honestly, so nobody has to rediscover them.

  • Link colours have no published hex. The guide names "University blue" and "bronze" but gives no values. This system uses #1F4E9C and #8C5F0A, both chosen to clear 4.5:1 on white and on the gold tint. Replace them if ANU publishes the real values.
  • No focus indicator is specified. Defined here as a 3px gold outline, since WCAG 2.1 requires one.
  • No border radius is specified. Read as square, matching ANU pages.
  • Button hover and focus states are not specified. Defined here.
  • Icons. The guide points to an ANU icon gallery rather than describing a class system, so this interface uses text and one drawn information symbol instead of an icon font.
  • Three guide pages 404. /steps/building-site/accessibility, /steps/building-site/tools/ and /steps/building-site/checklist are linked from the guide but return Not Found, so the accessibility rules here come from /web-style-guide/accessibility and the component pages instead.
  • Intrinsic layout on top of the fixed breakpoints. The ANU grid changes at 576, 768, 992, 1200 and 1400px, which leaves the widths in between laid out for a narrower screen than the one in use. The configuration band and the settings fields therefore use repeat(auto-fit, minmax(min(100%, 17rem), 1fr)), so the number of columns follows the space actually available at any width. Nothing on the page is sized in fixed pixels: widths are rem or percentages, and the terminal is clamp(16rem, 58vh, 50rem) so it fills a short laptop window and a tall monitor alike. The rem units mean the layout also responds to the reader's own font size, not just the window.
  • Public Sans is fetched from Google Fonts. On a machine with no network the page falls back to the system sans-serif; nothing else breaks.
  • Not an ANU site. This is a local research tool. It borrows the design language for consistency and has not been through the ANU approval process, which the guide requires before any real ANU site goes live.
